# Walmart Product Recommendation System

A content-based recommendation system that suggests similar products using product metadata and customer reviews.

## Overview
Processed 5K+ product listings and 60K+ reviews using NLP techniques, TF-IDF, and cosine similarity to generate personalized product recommendations.

## Tech Stack
Python, Pandas, Scikit-learn, NLTK

## Project Structure
Data preprocessing, feature engineering, similarity computation, and recommendations
